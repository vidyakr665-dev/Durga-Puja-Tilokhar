# Durga Puja GitHub Fixed Package

इस package में existing website के frontend files और तीनों poster images हैं।

मुख्य सुधार:
- स्थान: तिलोखर (रोहतास)
- तीनों posters `assets` folder में शामिल हैं
- automatic slider बना रहेगा

GitHub में upload करते समय:
1. Root में `index.html`, `style.css`, `app.js`, `config.js`, `config.example.js`, `receipt.html`, `admin.html` रखें।
2. Root के अंदर `assets` folder भी upload करें।
3. `assets` के अंदर ये तीन files होनी चाहिए:
   - poster-1-puja.jpg
   - poster-2-adhikarigan.jpg
   - poster-3-chanda.jpg
4. पुराने समान files को replace करें।

GitHub Pages को update होने में कुछ मिनट लग सकते हैं।
